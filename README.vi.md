## Gioi thieu

EasyGit la ung dung Git desktop duoc xay dung bang Electron, React, TypeScript va Vite. Muc tieu la giup Git de hieu hon nhung van giu lai du thong tin can thiet.

## Tinh nang chinh

- Mo repository co san hoac clone repository moi
- Xem changes, history, branches, stashes, tags va remotes
- Stage, unstage, discard, restore, commit, push, pull, fetch, merge, rebase va reset
- Co command palette va Git operation terminal
- Co phan cai dat giao dien, Git, diff, commit, thong bao, shortcut, plugin va advanced
- Bo cai dat Windows co the tao shortcut ngoai Desktop

## Tai ban da dong goi

Neu ban muon cai dat app cuoi cung, khong can clone source code. Hay tai installer tu GitHub Releases:

[Tai ban EasyGit moi nhat](https://github.com/phamtuandat2005/EasyGit/releases/latest)

Ban release nay chua:

- file cai dat Windows `.exe`
- icon cua app
- ho tro tao shortcut Desktop
- ho tro tao shortcut Start Menu

## Build tu source

```bash
npm install
npm run dev
```

Dong goi app:

```bash
npm run package
```
